## 🃏 Мой главный проект — [CardForge](https://github.com/PilotOfAsuka/CardForge)

**CardForge** — карточный игровой проект на **Godot / GDScript**, который я развиваю как расширяемую основу для разных карточных механик и режимов.

Это уже не просто эксперимент с движком: я уделяю всё больше внимания архитектуре, удобству интерфейса, сетевой игре и тому, как проект будет расти дальше.

**Что уже реализовано:**
- 🃏 Основа для карточной логики и игровых правил.
- 🎮 Локальный мультиплеер.
- 🌐 Сетевые комнаты через **WebSocket**: приватные и публичные.
- 📱 Версии для **Android** и **браузера**.

**[🌐 Играть в браузере](https://pilotofasuka.github.io/CardForge/) · [📱 Скачать APK](https://github.com/PilotOfAsuka/CardForge/releases/latest)**

**Над чем работаю:** развитие игровых режимов, единый UI/UX, рефакторинг и дальнейшее расширение мультиплеера.

> Иногда задача начинается словами «давай чуть-чуть улучшим», а заканчивается большим рефакторингом. 😂
